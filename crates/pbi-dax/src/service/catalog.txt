# DashCraft's DAX function catalog: signatures and one-line descriptions for
# completion, signature help, hover and argument-count diagnostics.
#
# The descriptions are DashCraft's own words. Line format:
#
#   NAME(param, [optional], [repeated]..., [name, expression]...) {min..max} -> returns | Description.
#
# `[…]` is optional, `…...` may repeat (any number of times), `{min..max}`
# overrides the argument count the parameters imply (`*` = no maximum).
# `## Title` starts a category. Every function the evaluator supports has a
# line (test `catalog_lists_every_supported_function`); the argument counts
# are checked against Power BI Desktop (`reference/groundtruth/recordings/dax-arity.json`,
# test `catalog_argument_counts_match_power_bi_desktop`).
