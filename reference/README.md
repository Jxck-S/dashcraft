# Reference fixtures

Test fixtures and example files. Tests find this folder at `$DASHCRAFT_REFERENCE` if that's set,
otherwise at `<workspace>/reference`; every path below is relative to it.

| Path | Committed? | What | Licence |
|---|---|---|---|
| `examples/acme-outfitters/` | yes | Synthetic "Acme Outfitters" retailer: a PBIP project (TMDL model, three PBIR reports), its CSVs, an offline blob map and expected values ([README](examples/acme-outfitters/README.md), [EXPECTED.md](examples/acme-outfitters/EXPECTED.md)) | Original synthetic content generated by `scripts/examples/gen_acme.py`; repository terms |
| `samples/microsoft/` | yes | Microsoft Power BI Desktop sample PBIX/PBIT files, pinned and hashed ([README](samples/microsoft/README.md)) | MIT (`samples/microsoft/LICENSE`); attribution in `THIRD_PARTY_NOTICES.md` |
| `samples/downloads/` | **no** (gitignored) | The large Microsoft samples, fetched by `scripts/fetch-samples.sh` | MIT |
| `golden/` | **no** (gitignored) | Optional PNG exports of the example's pages made by Power BI, for the golden-image (SSIM) comparison: `golden/<example>/<report>/<page>.png` with the report's short name (`--report`) and the page's display name, e.g. `golden/acme-outfitters/Overview/Executive Summary.png`. None are committed; a page without one prints `SKIP` ([details](../docs/VISUALS.md#golden-image-comparison)) | Yours; never commit |
| `private/` | **no** (gitignored) | Your own files (models, reports, data, live pulls); never committed | Yours |

**Rule:** a test that needs a gitignored file prints `SKIP: <file> missing` and returns
successfully when the file is absent, so CI on a fresh clone stays green. Renders, exports and other
outputs go under `target/` (e.g. `target/tmp/`), never into this folder.

## Acme Outfitters (`examples/acme-outfitters/`)

Regenerate with `python3 scripts/examples/gen_acme.py` (deterministic, standard library only) and
check DashCraft against it with `python3 scripts/examples/check_acme.py`. Paths for tests:

| Path | Use |
|---|---|
| `examples/acme-outfitters/AcmeOutfitters.pbip` | The project: open, inspect, lint, refresh, measures, render, convert, security |
| `examples/acme-outfitters/blob-map.json` | `--blob-map` / `DASHCRAFT_BLOB_MAP`: maps the placeholder container `https://acmeoutfittersdemo.blob.core.windows.net/sample-data` to `data/*.csv` |
| `examples/acme-outfitters/expected.json` | Expected values (schema below); `EXPECTED.md` is the readable form |
| `examples/acme-outfitters/AcmeOutfitters.SemanticModel/definition/` | TMDL files for round-trip tests (`tables/`, `roles/`, `expressions.tmdl`, `relationships.tmdl`, …) |
| `examples/acme-outfitters/Acme Outfitters - Overview.Report/` | PBIR report (`--report Overview`): Executive Summary, Product Detail, Time Intelligence |
| `examples/acme-outfitters/Acme Outfitters - Stores.Report/` | PBIR report (`--report Stores`): Store Performance, Store Detail (hidden), Store Tooltip (tooltip page); bookmarks |
| `examples/acme-outfitters/Acme Outfitters - Online.Report/` | PBIR report (`--report Online`): Online Overview, Customer Detail |
| `examples/acme-outfitters/data/*.csv` | Source CSVs (M evaluation, CSV loading, `data.loadCsv`) |

`expected.json` (`schemaVersion` 1) has `rowCounts` (after the M steps), `rawCsvRows`,
`dataQuality`, `calculatedTables`, `measures.unfiltered` and `measures.byReport` (every measure,
raw `value` and `formatted`), `calculationGroup`, `rls` (visible rows and totals per role/user),
`unrelatedReportFilter`, and `reports[].pages[]` with `cards[]` (one per card value: `visual` id,
`visualKey`, `visualType`, `measure`, `value`, `formatted`) and `visuals[]` (table/matrix totals and
rows, KPI, gauge, pie). An entry with `knownEngineGap` is an expectation DashCraft does not meet yet.
