# ADR-0029: Ground truth from Microsoft's TMDL reader

- Status: Accepted
- Date: 2026-11-07
- Deciders: the project owner
- Related: [ADR-0011](0011-desktop-ground-truth.md) (ground truth from Power BI Desktop; this ADR
  adds a second oracle under the same rules), [ADR-0003](0003-vertipaq-xpress9-cleanroom.md)
  (clean-room rules), [reference/groundtruth/README.md](../../reference/groundtruth/README.md#tmdl-suites)
  (how to record), [DESKTOP-PLAN.md M7.4](../DESKTOP-PLAN.md#m7-language-foundation). Numbers
  0016 to 0028 are reserved for the proposals listed in DESKTOP-PLAN, so this decision takes the
  next free number.

## Context

The TMDL language service (M7.4) underlines what Power BI Desktop would refuse to open: unknown
or misplaced keywords, wrong forms and values, keywords above the compatibility level, references
to missing objects. Desktop reads TMDL with the Tabular Object Model's TMDL reader
(`TmdlSerializer`). Desktop's GUI only shows that a project failed to open, one error at a time,
so probing thousands of keyword, form and value combinations through it is impractical.

The same reader ships on its own as the `Microsoft.AnalysisServices` NuGet package (the TOM
client library). Its documented API deserializes a TMDL folder into a database object or throws
an exception with a message, without any server, and runs headless in well under a second per
model.

## Decision

1. **TOM's TMDL reader is an oracle for TMDL validity.** A recorder
   (`scripts/groundtruth/Record-Tmdl.ps1`) loads the package (downloaded once into
   `target/groundtruth/tools/tom`, never committed or shipped), applies each corpus case to a
   copy of a synthetic fixture and calls `TmdlSerializer.DeserializeDatabaseFromFolder`. It
   records only the verdict: success, or the exception type and message, normalized to a short
   token (`unknown`, `type:<T>`, `unresolved`, `compat`, …).
2. **Black box only**, as in ADR-0011 decision 1: the documented API, its results, exceptions and
   messages. No disassembly, decompilation, reflection over internals, debugging or reading of
   the package's code or resources. The keyword lists, value types and enumerations DashCraft
   uses are generated from the recorded verdicts (`crates/pbi-tmdl/src/service/catalog.txt`),
   not copied from the library.
3. **Same artefacts and rules as ADR-0011.** Corpora `reference/groundtruth/corpus/tmdl-*.json`
   (generated by `gen_corpus.py`, checked with `--check`), recordings
   `reference/groundtruth/recordings/tmdl-*.json` naming the TOM version, a comparison test
   (`crates/pbi-tmdl/tests/groundtruth.rs`), and the shared deviation ledger
   (`reference/groundtruth/deviations.json`) that only shrinks. Inputs are the synthetic
   `tmdl-probe` fixture, the Acme Outfitters example and edits of them.
4. **Desktop stays the reference for behaviour.** TOM decides whether TMDL loads; what a loaded
   model computes and how Desktop saves it are still recorded from Desktop (ADR-0011, GT-4).
   When TOM and Desktop could disagree (a Desktop release bundling another TOM version), the
   recording names the TOM version and is re-recorded like Desktop recordings.

## Alternatives considered

| Option | Why not |
|---|---|
| Probe through Power BI Desktop's GUI | One error per open, minutes per case, UI automation of error dialogs; thousands of probes are impractical |
| Write the rules from the public TMDL documentation alone | The documentation lists objects and properties but not every form, level or accepted value (for example which enumerations take integers, which keywords take `= value`) |
| Derive the rules from the library's metadata by reflection | Inspects the binary rather than its behaviour (ADR-0003 rule 3) |

## Consequences

- `cargo test -p pbi-tmdl --test groundtruth` compares the language service with the recordings
  on every platform; recording needs PowerShell 7 and .NET 8 (any OS; recorded on Windows), not
  Desktop.
- A new TOM release may change verdicts; re-recording is a reviewed diff, and the catalog is
  regenerated from it (`DASHCRAFT_BLESS=1`).
- The recordings hold short exception messages of the reader (for example "Cannot read or find
  the Type property of 'BindingInfo' object."), recorded from synthetic input like Desktop's
  query errors.
