## 1. Rust crate dependencies

License compliance for Rust dependencies is enforced in CI by [`cargo-deny`](https://github.com/EmbarkStudios/cargo-deny) using [`deny.toml`](deny.toml). Only the permissive licenses on its allow list pass; copyleft and unknown licenses fail the build.

The inventory below lists every third-party crate compiled into the shipped binaries (the `dashcraft` CLI, its `pbiview` alias, and the desktop app `dashcraft-app`). Regenerate it with `scripts/license-inventory.py` after changing dependencies (CI warns when it is stale; see [docs/packaging.md](docs/packaging.md#license-inventory-and-sbom)). Release builds also ship `licenses/THIRD_PARTY_LICENSES.txt`, the full license and notice files of every listed crate and npm package, and attach CycloneDX SBOMs to the GitHub release.
